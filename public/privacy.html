سياسة الخصوصية — دحروج Quest

آخر تحديث: 8 أكتوبر 2026. المسؤول عن اللعبة: Aboden Games.

البيانات المحلية

نحفظ الإعدادات، اللغة، نتائج التحديات، الزينة وأفضل النتائج في IndexedDB على جهازك. يحفظ Service Worker ملفات اللعبة للعمل دون اتصال. لا تتضمن اللعبة حسابات أو مزامنة سحابية أو إعلانات أو تحليلات استخدام أو إرسال تقارير أعطال تلقائيًا.

الواقع المختلط ووحدات التحكم

نستخدم WebXR لقراءة وضع الرأس ووحدات التحكم وحالة التتبع والتركيز. عند السماح بميزات الغرفة، تُستخدم نتائج hit-test ومستويات الغرفة والمراسي مؤقتًا لوضع المجسمات والتصادم. لا نرسل هذه البيانات ولا نخزن خريطة غرفتك. تدير Meta صورة العبور passthrough؛ لا تقرأ اللعبة صور الكاميرا أو الميكروفون أو GPS. ميزات الغرفة الاختيارية تعمل حسب الأذونات وإمكانات المتصفح.

الاستضافة والخدمات الخارجية

نسخة التجربة على نطاق chatgpt.site تستضاف عبر ChatGPT Sites وتبقى خاصة بمالكها؛ قد تتطلب تسجيل الدخول بحساب ChatGPT. تتولى OpenAI ومزودو خدماتها بيانات المصادقة وسجلات الطلبات، بما فيها عنوان IP ومعلومات المتصفح ووقت الوصول، وفق سياسة OpenAI. هذا تسجيل دخول لخدمة الاستضافة، وليس حسابًا داخل اللعبة أو مزامنة لتقدمك.

تتصل اللعبة بأصل الاستضافة نفسه لتنزيل الشفرة والنماذج والموسيقى والخطوط. عند استخدام النشر على Vercel، قد يعالج مزود الاستضافة عنوان IP، الطلب، وقت الوصول ومعلومات المتصفح لأغراض التوصيل والأمن وسجلات الخادم وفق سياسة Vercel. ليست هذه السجلات مزامنة لنتائجك. تدير Meta المتصفح ونظام النظارة وفق سياسة Meta. يجب تحديث هذه الصفحة قبل تغيير المزود أو إضافة خدمة بيانات.

القياس والتصدير

تبقى عدادات الأداء مؤقتًا في ذاكرة الجلسة. زر «تصدير قياس الأداء» ينزّل ملف JSON إلى جهازك، ولا يرفعه إلى Aboden Games. يضم أزمنة الإطارات وعدد العناصر واستخدام الذاكرة عند توفره. إذا شاركت الملف بنفسك، يتلقى المستلم ما يحتويه.

الحذف والتواصل

استخدم «حذف الحفظ المحلي» في صفحة الدخول لمسح التقدم والإعدادات. لمسح الملفات المخزنة أيضًا، احذف بيانات الموقع من إعدادات Meta Quest Browser. لا توجد نسخة تقدم على خادمنا لاستعادتها. للاستفسار أو طلب مساعدة في الحذف استخدم قناة الدعم العامة لـ Aboden Games على GitHub؛ لا تنشر بيانات حساسة فيها. تعالج GitHub ما ترسله وفق سياستها. طلبات تخص سجلات الاستضافة أو المنصة تُعالج لدى مزودها.

الأطفال والأمان

لا تطلب اللعبة اسمًا أو بريدًا أو عمرًا. يخضع الوصول لحساب Meta وضوابط الأسرة والتصنيف العمري الذي تعتمده المنصة. لا يتجاوز هذا الوصف وجود سجلات الاستضافة المذكورة. تُنقل ملفات اللعبة عبر HTTPS؛ لا يمكن ضمان أمان مطلق. يتغير تاريخ هذه الصفحة عند تغيير الممارسات.

Privacy Policy — Dahrooj Quest

Updated October 8, 2026. Game operator: Aboden Games.

Local storage and XR

Settings, language, challenges, accessories and high scores stay in device IndexedDB. A service worker caches game files. There are no game accounts, cloud saves, advertising, usage analytics or automatic crash uploads. WebXR head/controller poses, tracking state, optional room planes, hit tests and anchors are used transiently for interaction and placement. Room geometry is not uploaded or persisted. Meta controls passthrough; the game does not read camera images, microphone audio or GPS.

Hosting and platform services

The private test deployment on chatgpt.site is hosted with ChatGPT Sites and may require the owner to sign in to ChatGPT. OpenAI and its service providers process authentication data and request logs, including IP addresses, browser information and access times, under the OpenAI privacy policy. This hosting sign-in is separate from the game; it does not synchronize game progress.

The application downloads its code and assets from its own origin. When deployed on Vercel, that provider may process IP addresses, request details, timestamps and browser information for delivery, security and server logs under its linked privacy policy. Meta operates the browser and headset under its own policy. These services are separate from local game progress. This policy must be updated before changing hosts or adding data services.

Export, deletion and support

Performance counters stay in session memory. Export downloads a JSON file locally; no automatic upload occurs. Sharing that file is your choice. Use “Delete local save” on the entry page to erase progress/settings; clear site data in Quest Browser to remove cached files too. There is no server-side progress backup. The existing public Aboden Games support channel accepts questions and deletion-help requests. Do not post sensitive information there; GitHub processes submissions under its own privacy policy. Contact the hosting/platform provider for their logs.

The game does not request a name, email or age. Meta account, family controls and platform age ratings govern access. Hosting logs still exist as described above. Files are delivered over HTTPS; absolute security cannot be guaranteed.
