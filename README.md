# دحروج Quest — Aboden Games

إعادة بناء مستقلة باستخدام TypeScript وMeta IWSDK وHavok. المستودع الإنتاجي الوحيد هو [3wasfnjd/Dahrooj-Quest](https://github.com/3wasfnjd/Dahrooj-Quest). المستودع القديم `3wasfnjd/quest` مرجع للقراءة فقط، ولم يُعدّل.

**الحالة: نسخة هندسية تحت التحقق، وليست إصدارًا جاهزًا للمتجر.** يوجد تنفيذ للأنماط التسعة وVR وMR، مع اختبارات آلية. النشر الدائم، ربط Meta، التوقيع وDigital Asset Links تحتاج بيانات المالك الحقيقية. راجع [التقرير](docs/FINAL-REPORT-AR.md) و[المشكلات](docs/KNOWN-ISSUES-AR.md).

> لم يتم اختبار هذه النسخة على جهاز Meta Quest حقيقي، لذلك لا يمكن اعتبارها جاهزة نهائيًا للنشر في المتجر.

## التشغيل والتحكم

اللعب داخل Meta Quest Browser في `immersive-vr` أو `immersive-ar` فقط. صفحة الدخول العادية تختار الجلسة وتعرض الخصوصية والحذف وتصدير القياس؛ لا تحتوي لعبة هاتف أو حاسوب.

| اليد | التحكم | الفعل |
|---|---|---|
| اليمنى | Grip | التقاط دحروج قريب أو إنشاء دحروج؛ الإفلات يرميه |
| اليمنى | Trigger | شحن الرمية عند اختيار Charged؛ اختيار القائمة/تأكيد موضع MR |
| اليمنى | A | استدعاء الكرات؛ قفز في Summit؛ تبديل حجم معاينة MR |
| اليمنى | B | الأنماط/إغلاق القائمة؛ وضع MR اليدوي أثناء المعاينة |
| اليسرى | Trigger | إطلاق تلقائي؛ قذيفة الشخصية في Summit |
| اليسرى | Grip | مرساة المقلاع؛ اسحب اليد اليمنى للخلف ثم أفلت Grip الأيمن |
| اليسرى | X / Y | التحديات / الإعدادات |
| اليسرى | العصا | يمين/يسار في Summit فقط |

في فقدان التركيز يتوقف الإدخال والمحاكاة وتختفي وحدات التحكم. القائمة توفر إعادة النمط، إعادة موضع AR والخروج من XR؛ الإعدادات توفر إعادة توجيه العالم في VR دون تحريك الكاميرا.

## العمل كاملًا من الهاتف والسحابة

1. افتح هذا المستودع من Safari على iPhone. تعديل الملفات عبر GitHub أو محرر `github.dev`، وتشغيل المهام من تبويب **Actions**؛ لا يلزم تثبيت Node أو Android Studio على جهازك.
2. كل push/PR يشغّل **Check** و**XR Test**. **Web Build** ينتج ملفات HTTPS في Artifact. التقارير ولقطات المحاكاة مرفقة في Actions.
3. اتبع [إعداد النشر والتوقيع من الهاتف](docs/CLOUD-SETUP-AR.md) مرة واحدة لربط مشروع Vercel جديد، أصل HTTPS دائم، تطبيق Meta الجديد والشهادة الدائمة.
4. **Deploy HTTPS** ينشر تلقائيًا بعد ضبط الإعدادات. **Quest APK** يُشغّل يدويًا من الهاتف برقم إصدار جديد، وينتج APK موقّعًا وSHA-256 وتقارير التحقق إذا اجتازت المتطلبات.
5. اختبر الرابط على نظارة حقيقية وسجّل القياسات وفق [بروتوكول الأداء](docs/PERFORMANCE-REPORT-AR.md). لا توجد مهمة تنشر إلى متجر Meta تلقائيًا.

## البنية والإصدارات

IWSDK **1.0.1**، Three.js **r181** عبر `super-three@0.181.0` المتوافق مع SDK، Havok **1.3.14**، Vite **7.3.7**. WebGL2 إلزامي؛ WebGPU غير مستخدم. فيزياء Havok داخل Worker عند **60 Hz** مع interpolation، مستقلة عن الرسم. طلب 72 Hz تفضيل مشروط بالدعم وليس قياسًا للأداء.

المصدر داخل `src/`، والأصول المرخصة داخل `assets/`. `public/assets` و`public/vendor` نواتج تجهيز تُولّد ولا تُكرر في Git. لا توجد مكتبات تشغيل من CDN. المحاكي IWER متاح للتطوير/الاختبار فقط ويُستبعد من الإنتاج. الحفظ IndexedDB بإصدار ومهاجرات؛ الواجهات عربية وإنجليزية وخطوط محلية.

## أوامر بيئة التطوير السحابية

هذه الأوامر تخص CI أو Codespaces، وليست متطلبات على جهاز المالك:

```sh
npm ci
npm run check
npx playwright install --with-deps chromium
npm run test:xr
npm run test:production
```

`npm run dev` يشغل محاكي IWSDK للتطوير. `VITE_XR_AUTOMATION=1` يستعمل IWER داخل اختبارات المتصفح فقط. `npm run build` ينتج `dist/`؛ يجب استضافته من جذر أصل HTTPS لكي يعمل `/.well-known/assetlinks.json`.
