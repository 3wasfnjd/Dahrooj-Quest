# معمارية دحروج والمقياس

التاريخ: 2026-10-08. بُني المشروع بعد تدقيق المرجع، دون نقل `index.html` أو `xr.js` أو Matter.js أو Three r128 أو الحالة العامة القديمة.

## ملكية الحالة ودورة الحياة

ينشئ `main.ts` عالم IWSDK ثم يحقن GameContext خاصًا بالعالم عبر WeakMap. المكوّنات Dahrooj وProjectile وModeOwned وTransform وPhysicsBody/Shape تربط كيانات ECS بالأنظمة. Input ثم Session/MR ثم PlayerRig/Throw ثم Havok ثم الشخصيات والقذائف ودورة النمط ثم البيئة والصوت والقياس. أنظمة SDK مسؤولة عن تحديث XR والرسم والفيزياء؛ لا توجد حلقة رسم موازية أو تحريك مصطنع للرأس.

ModeLifecycle يمتلك نمطًا واحدًا فقط. عند التبديل، ModeScope يزيل كيانات الفيزياء والأهداف والمجسمات والخامات الخاصة بالنمط السابق، ويصفّر تجمعات المقذوفات. لا تُنشأ بقية الأنماط حتى تُفعّل. النظام العام يستدعي النمط الحالي فقط. المواد والهندسات المشتركة مملوكة لـResources ولا تُتلف عند تبديل النمط. نواتج تحميل البيئة القديمة ترفض الإضافة عند تغير رقم دورة حياتها.

| النظام | المسؤولية |
|---|---|
| XRSessionSystem / PlayerRigSystem | بدء/إنهاء VR أو AR؛ تركيز النظام؛ إخفاء التحكم؛ الاستعادة |
| ControllerInputSystem / ThrowSystem | العينات، الحواف، الرمي الثلاثي والالتقاط والاستدعاء |
| PhysicsSystem + Bodies | Havok، الأشكال والكتلة والنبضات والـWorker |

| GameModeLifecycleSystem | نمط وحيد، التسجيل والتصادم الممسوح والتخلص |
| EnvironmentSystem | الطبيعة والماء والصناديق والوقت والطقس |

## القياس والفيزياء

العالم متري: الوحدة متر. الجاذبية العامة 9.81 م/ث². نصف قطر دحروج 0.13 م وكتلته 0.38 كغ؛ restitution=0.48 وfriction=0.55، linearDamping=0.06 وangularDamping=0.14. السرعة ≤18 م/ث والدوران ≤45 راديان/ث. التكامل الداخلي Havok ثابت 60 Hz مع interpolation وWorker. `PhysicsManipulation.force` في نسخة SDK الحالية نبضة؛ القوى المستمرة تُحوّل إلى mass×acceleration×dt. لا يوجد soft-body حقيقي. تشوه الشخصية لا يغيّر مصادمها الكروي.

عينات الرمي في حلقة 24 عنصرًا؛ نافذة تقدير 20–110 ms مرجّحة، مع رفض انقطاعات التتبع والقفزات. فرق quaternion يقدّر الدوران. Magnus تقريبي `spin × velocity × 0.008` بحد تسارع 3.2 م/ث² أو 22% من السرعة، أيهما أصغر. المقلاع يسحب بين اليدين حتى 0.7 م؛ التنبؤ 24 نقطة بالستية فقط ولا يضمن اصطدامات المشهد. Charged يتراوح بين 3 و15 م/ث. توجد حماية sweep تكمّل Havok للأسطح الرفيعة؛ لا ندّعي تفعيل CCD غير موثق في SDK.

| القرار | القيمة/السبب |
|---|---|
| Goal | عرض 4.6 م وارتفاع 2.2 م، على بعد 5.2 م؛ رمي ثابت |
| Hoop | ارتفاع الحلقة 2.18 م ونصف قطر 0.37 م؛ وصول مريح لا محاكاة ملعب احترافي بالمقاييس الرسمية |
| Cans | 6 علب، كتلة 0.09 كغ للعلبة، طاولة بارتفاع 0.85 م |
| Bowling | 10 دبابيس ConvexHull جديدة، 0.5 كغ، تتبع سقوط ورميتين وإعادة |
| Window | فتحة 1.15 م، تتناقص 15% إلى 0.34 م أو حد يراعي حجم الكرة في MR |
| MR | أرض 1:1، طاولة 0.22، جدار 0.55؛ لا تغيير لحجم اللاعب أو XR origin |
| كرة MR | نصف القطر لا يقل عن 0.045 م لتسهيل الالتقاط؛ الكتلة تتناسب مع حجمها |
| Summit | شخصية 0.074 م، قفز 2.22 م/ث، جاذبية 4.8 م/ث² للعبة المنصات المصغرة؛ 37 صعودًا ×0.32 م |

Summit يستخدم متحكم منصات ثنائي الأبعاد ثابت 60 Hz مستقلًا عن مصادمات رميات Havok. هذا قرار صريح للحركة المقصودة وcoyote/jump-buffer، وليس الادعاء بأن Havok يحاكي منصات Summit. أربع مناطق، 3 قلوب، checkpoints، حصانة، منصات متحركة ومتفتتة وجليد وشوك وجليد ساقط وCrawler/Bat/Spitter. اللاعب يرى مسرحًا جبليًا ثابتًا تتغير محتوياته، ولا تتحرك كاميرته. MR يعرضه مصغرًا. اجتياز المسار كاملًا على النظارة لا يزال مطلوبًا.

## ميزانيات لا تُتجاوز

16 دحروجًا قريبًا، 32 قذيفة، 24 شظية، 256 مؤثرًا و24 مستوى غرفة. Rain يبدأ بـ120 جسمًا مرسومًا بالـinstancing، ويقل إلى 100 ثم 80 عند انخفاض الأداء؛ لا يزيد المرقّى إلى Havok عن 8 ضمن تجمع الكرات. العشب رقع مثلثة مجمعة مع shader wind وLOD كثافة وقص مسافة/frustum. الحطام يعيد استخدام كياناته. Fair يفعل فيزياء البط المصاب فقط.

QualitySystem يراجع متوسط زمن الإطار كل 4 ثوانٍ، ويقلل الزينة ويرفع foveation عند تجاوز 17.5 ms؛ الرجوع يتطلب 4 نوافذ سليمة. لا يغير تردد الفيزياء أو قواعد التسجيل. هذا تحكم بالعبء، وليس شهادة تحقق الأداء.

Jelly يوهم بالامتصاص والفريسنل دون أخذ عينة من الشاشة، Fabric خامة محبوكة وغرز، Clay أثر أصابع إجرائي، Fur بقع ووهم وبر وربطة حمراء، Bubble سطح رقيق واحد بلا depthWrite. لا شعر حقيقي ولا refraction متعددة المرور. الوجوه مجسمات مشتركة و9 حالات، لا CanvasTexture جديدة لكل إطار. واجهة اللعب تستخدم لوحتين CanvasTexture دائمتين تتحدثان عند تغير النص فقط.

## MR والخصوصية

التطبيق يكتشف دعم جلسات وميزات XR، دون user-agent sniffing. AR شفاف؛ لا يحجب passthrough بخلفية السماء. hit-test هو مسار raycast البيئي المتاح، وليس API وهميًا مستقلاً. عند غيابه، تبقى معاينة يدوية وتأكيد بالزناد. مستويات الغرفة تتحول إلى صناديق رفيعة محدودة العدد، لا شبكة غرفة معقدة. التخزين لا يحفظ المضلعات أو الصور. انحراف مرساة أكبر من 5 سم يعيد بناء الوضع الحالي؛ هذه الاستعادة قد تصفّر الجولة ويجب تقييمها على النظارة.

## الصوت والتحميل

Web Audio محلي بخمس مجموعات، أصوات مكانية ومؤثرات buffer مخزنة و16 صوتًا متزامنًا. موسيقى Aboden الأصلية أُعيد تصيير لحنها مسبقًا إلى OGG (60 ثانية، F major، 96 BPM)؛ لا مؤلف إجرائي يعمل كل إطار. جميع GLB والخطوط والموسيقى ونماذج Touch وWASM من أصل التطبيق. URL modifier وCSP يمنعان تحميل CDN. `connect-src data:` يسمح بـWASM المضمّن محليًا في Yoga ولا يضيف خادمًا خارجيًا.

Service Worker يخزن ناتج البناء تحت بصمة إصدار، ولا يعترض Digital Asset Links. الاختبار الإنتاجي يتحقق من CSP والتخزين والوصول للخصوصية دون اتصال. لا يكفي اختبار بوابة الإنتاج لإثبات جلسة XR إنتاجية على Quest.
