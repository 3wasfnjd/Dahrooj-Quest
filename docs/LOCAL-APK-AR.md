# دحروج — APK محلي تجريبي

11 أكتوبر 2026. جرى بناء حزمة أندرويد فعلية موقعة تضم ملفات اللعبة. تفتح اللعبة في **Meta Quest Browser** من خدمة محلية داخل النظارة. ليست نسخة Unity ولا تطبيق XR مستقلًا عن المتصفح. **لم تُختبر هذه الحزمة على Quest فعلية بعد.**

## محتويات النسخة

- الحزمة `com.abodengames.dahrooj.localtest`، الإصدار `0.1-local-test`، رقم البناء `1`.
- المصدر `95dac398081d6f0c047db3cb4e7fde4efd42fd27`، بناء اللعبة `c19a44cfa3cff2`.
- APK حجمه **6,537,028 بايت**، يحتوي **119 ملفًا** للعبة بحجم إجمالي غير مضغوط **11,652,991 بايت**.
- ملفات الرسم والفيزياء والأنماط والقوائم لم تتغير. الملفات الـ118 غير `sw.js` مطابقة للبناء السابق حرفيًا.
- استُبدل `sw.js` داخل نسخة APK فقط بعامل خدمة لا ينزّل تحديثات ولا يحتاج زيارة سابقة لتخزين اللعبة. الملفات تأتي من APK في كل تشغيل. لا يمسح العامل الجديد localStorage أو IndexedDB.
- يستمع الخادم على `http://127.0.0.1:48189/` فقط، ولا يفتح منفذًا على شبكة Wi-Fi. المنفذ ثابت للحفاظ على عنوان الحفظ.
- إذن Android المسمى `INTERNET` مطلوب لمقبس loopback المحلي. الغلاف لا يحتوي عميل تنزيل أو تحليلات أو تحديثات. متصفح Meta تطبيق منفصل؛ لا نتحكم في اتصالاته الداخلية.

## تجربة النظارة المطلوبة

1. ثبّت `Dahrooj-local-test-v1.apk` على Quest عبر أداة تثبيت APK/ADB مصرح لها في وضع المطور. عند توفر حاسوب متصل بالنظارة: `adb install -r Dahrooj-local-test-v1.apk`.
2. **قبل أول تشغيل، أوقف Wi-Fi.** لا تفتح الموقع المستضاف بغرض تخزين اللعبة مسبقًا.
3. افتح «دحروج · محلي» ثم «تشغيل اللعبة». يفترض أن يفتح متصفح Quest شاشة اختيار VR وMR.
4. جرّب الوضعين والأنماط والقوائم، وعدّل لونًا أو إكسسوارًا. اخرج وأعد التشغيل للتحقق من الحفظ، ثم أعد تشغيل النظارة مع بقاء Wi-Fi مغلقًا وجرّب مجددًا.
5. اترك خدمة دحروج تعمل أثناء اللعب. أوقفها من زر التطبيق أو إشعاره بعد الانتهاء. إذا أوقفها النظام، أعد تشغيل اللعبة من التطبيق.

إذا لم يفتح المتصفح آليًا، أدخل العنوان المحلي أعلاه في **متصفح النظارة نفسها** أثناء عمل الخدمة. إذا لم تُفعّل أزرار XR أو توقفت الخدمة عند الدخول إلى اللعب، فهذا فشل في اختبار الجهاز يجب توثيقه؛ لا يُعد فتح الموقع المستضاف نجاحًا لهذا الاختبار.

الحفظ منفصل عن حفظ الموقع السابق لاختلاف عنوان الأصل. يبقى داخل مساحة تخزين ذلك العنوان في المتصفح. لا تمسح بيانات المتصفح إذا أردت الاحتفاظ به. لا ترحّل هذه النسخة تقدم الموقع تلقائيًا.

## إعادة البناء

المتطلبات: Python 3، JDK 21، Android SDK Platform 34 وBuild Tools 36.0.0. أدوات البناء 36 تعالج عدم توافق D8 القديم مع مخرجات JDK 21؛ يبقى `minSdk=32` و`targetSdk=34` و`compileSdk=34`.

```sh
npm ci
npm run build
python quest-package/local/build.py --sdk "$ANDROID_SDK_ROOT" --jdk "$JAVA_HOME"
npx playwright install chromium --only-shell
node quest-package/local/test-browser.mjs
```

يستخدم اختبار المتصفح `JAVA_HOME` ويقبل `PLAYWRIGHT_CHROMIUM_EXECUTABLE` لمتصفح مثبت. يتطلب البناء أولًا؛ يختبر الملفات نفسها المجمّعة داخل APK عبر خادم Java نفسه، مع منع طلبات صفحات اللعبة إلى الخارج.

المخرجات داخل `release/`: APK وبصمته وتقريرا البناء والمتصفح. مفتاح **التجربة** في `quest-package/generated/local/local-test.keystore`، اسمه `androiddebugkey` وكلمة مروره العامة `android`. ليس مفتاح إصدار تجاري؛ احتفظ به محليًا لإعادة تثبيت تحديث تجربة فوق الحزمة نفسها. لا ترفعه إلى Git ولا تستخدمه للإصدار النهائي.

بصمة APK لهذا التسليم: `bc0e017f3c153d93e872a01298d8293858f9dbb34d57b005d82c827d3568dfd1`.

المصدر والاختبارات في `quest-package/local/`. مهمة Bubblewrap القديمة الخاصة بالأصل المستضاف مسار مختلف ولا تبني هذه الحزمة. مصدر الحزمة لا يحتاج Gradle أو Unity أو حساب Unity.
