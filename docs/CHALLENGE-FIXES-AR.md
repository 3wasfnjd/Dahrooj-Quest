# مراجعة التحديات وتخفيف دحاريج العالم

## الشروط

| التحدي | الشرط المعتمد |
|---|---|
| أهداف الحارس | ٣ أهداف ناجحة، تراكمية |
| السلات | ٣ نجاحات متتابعة؛ الفشل أو الاستدعاء قبل النجاح أو تغيير النمط يقطع السلسلة |
| الشباك | الوصول فعليًا إلى أصغر حجم |
| العلب | صف كامل، رمية واحدة محددة؛ الرمية الثانية أو مساعدة المسدس تلغي أهلية الصف |
| الاستايلات | استخدام الاستايل أثناء الرمي/اللعب، لا مجرد اختياره في القائمة |
| القمة | حدث الوصول الفعلي إلى القمة |
| الوحوش | ١٥ هزيمة فعلية؛ حدث الدوس أو إصابة المقذوف |
| البولينغ | إسقاط الصف الكامل في الرمية الأولى دون مساعدة المسدس أو كرة أخرى |
| الصناديق | ٥ أحداث انفجار فعلية |
| تفجير السماء | بديل التربيت: تفجير ٥ دحاريج بالطلقات أعلى من الرأس بـ٢٥ سم على الأقل؛ ارتفاع الرأس ومقياس XR يؤخذان في الحساب |
| الأهداف الملتفة | ٣ أهداف ناجحة، خاصية الالتفاف محفوظة لكل كرة منفصلة |
| الطوب | ٢٠ طوبة مكسورة، تراكمية |
| الحائط | تحطيم جميع طوب الحائط |
| الملاهي | ٢٥ نقطة داخل جولة واحدة؛ التقدم الحالي لا يُجمع من جولات مختلفة |
| الجرس | ٣ إصابات للجرس، مع مهلة الحركة لمنع تكرار الإصابة نفسها |
| تفجير دحاريج | ٢٠ تفجيرًا فعليًا، تراكمية |

التحديات المكتملة المحفوظة سابقًا تبقى محفوظة: لا توجد بيانات تعيد إثبات صحة كل إنجاز قديم. يمكن تصفيرها من القائمة لاختبار الشروط الجديدة. التحدي البديل له معرف جديد ولا يرث إنجاز التربيت. التحديات التي اكتملت بالشروط الجديدة تبقى مكتملة حتى عند بدء محاولة أخرى.

## القائمة

٨ تحديات في الصفحة، صفحتان بأزرار السابق/التالي، وخط العنوان ٣٦ بكسل بدل نحو ٢١ بكسل، مع التفاف النص والعداد المنفصل ودعم العربية والإنجليزية.

## حدود الأجسام

- دحاريج متبقية بعد انتهاء الرمية: ٨ بدل ٣٦؛ عمر ١٢ ثانية فعلية مع تقلص خلال آخر ٠٫٧٥ ثانية.
- الكرات الإضافية المتزامنة: ٣ بدل ٦، بجانب الكرة الحالية.
- المطر: ١٠٠ بدل ٢٢٠ في VR، و٧٢ بدل ١٣٠ في AR، بالرسم المجمّع نفسه.
- الطلقات المتزامنة: ١٦ بدل ٣٢.
- شرر الطلقات: حد ١٢٨؛ شرر المطر: حد ٨٠.
- استدعاء dispose لمواد الوجه الخاصة بالنسخ المحذوفة، والتخلص من مواد الشرر عند تفريغ المؤثرات. المواد والهندسات المشتركة تبقى لإعادة الاستخدام.

اختبارات الانحدار تستخدم اصطدامات العلب الفعلية وتغطي الرمية الواحدة والرميتين ومساعدة المسدس. اختبار XR يولّد ٢٠ كرة منتهية ويتحقق من حد الثماني ثم انتهاء عمرها. هذه إثباتات حدود وسلوك، وليست قياسات FPS أو ذاكرة على النظارة.

لم يتم اختبار هذه النسخة على جهاز Meta Quest حقيقي، لذلك لا يمكن اعتبارها جاهزة نهائيًا للنشر في المتجر. لا يمكن تأكيد زوال الوميض على الجهاز بالاختبار البرمجي وحده.
