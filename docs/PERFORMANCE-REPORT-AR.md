# تقرير الأداء — دحروج Quest

التاريخ: 2026-10-08. **لا توجد قياسات من Meta Quest حقيقي.** الأرقام التالية تشخيص من حاوية Linux بمحاكاة IWER 2.5.0 وChromium 153.0.8010.0 وSwiftShader (رسم برمجي). ليست قياسًا لمعالج Quest أو GPU النظارة، ولا دليلًا على 60/72/90 FPS. المقارنة بين أداء هذا المحاكي وأداء النظارة غير صالحة.

## القياس الفعلي المتاح

الاختبار يبدّل الأنماط ويضغط التجمعات ويفتح القوائم ويجرب الخامات، وليس benchmark ثابتًا لنمط واحد. الجلسة آخرها Cans لكن القياس يجمع الجزء النشط من السيناريو كله. الدليل الخام: [simulator-performance.json](evidence/simulator-performance.json).

النتيجة: هذا الاختبار البرمجي بطيء عن هدف اللعبة، ولا نعيد تفسيره كنجاح أداء. يلزم قياس فعلي قبل أي قبول Store. `performance.memory` غير محمول لكل المتصفحات؛ يعيد الحقل null عند غياب API. زمن إطار طويل ليس دليل GC، لذلك لا نخترع توقفات GC.

## قياس GitHub Actions المستقل

شغّل [XR Test رقم37802348747](https://github.com/3wasfnjd/Dahrooj-Quest/actions/runs/37802348747) نفس السيناريو بنجاح على الشفرة `6c592f1f524983a6969b30d1079ecc633b078b20`، باستخدام Chromium156.0.8078.4 وSwiftShader. سجّل176 عينة خلال83.205 ثانية: متوسط **2.12FPS**، متوسط إطار **472.75ms**، وp95 **923.70ms** وp99 **1384.50ms**. JS heap81,400,000 بايت، أعلى draw calls198 وأعلى triangles214,960 وأجسام Havok63. البيانات الأصلية في [simulator-performance.json](evidence/github/simulator-performance.json).

هذا نجاح وظيفي للاختبار فقط؛ أداء الرسم البرمجي في CI بطيء جدًا ولا يثبت اجتياز حد الأداء. ينتظر اختبار الجاذبية هبوطًا فعليًا أكبر من20سم ضمن مهلة محدودة بدل افتراض تقدم المحاكاة بعد700ms من وقت الخادم. لا يخفف ذلك شرط الهبوط ولا يبدل الفيزياء. اختبارات النظارة وقياسها ما زالت بوابة قبول مستقلة.

## الحجم

| المحتوى | البايت |
|---|---:|
| ناتج Web كامل غير مضغوط | 10,857,657 |
| مجموع gzip لكل ملف | 6,281,442 |
| JavaScript كامل | 2,458,597 |
| الملفات | 115 |
| APK | غير مولد، فلا قياس |

الحجم الخام 10.35 MiB. رقم gzip تقدير نقل يجمع ضغط كل ملف، وليس قياس شبكة أو حجم ZIP/تثبيت. المصدر لهذه الأحجام هو Web Build الناجح في GitHub Actions للشفرة `6c592f1f524983a6969b30d1079ecc633b078b20`: [bundle-size.json](evidence/github/bundle-size.json). يبقى سجل البناء المحلي الأسبق في `evidence/bundle-size.json` منفصلًا؛ قد تختلف بضعة بايتات في البيانات المولدة. حد CI للويب 24MiB ولـJS 8MiB؛ ميزانية APK داخلية 100MiB مع فحص سقف Meta الحالي مستقلًا. حجم ZIP المنشور كـArtifact للويب 6,299,106 بايت؛ هذا ليس APK. لا IWER أو test bridge أو CDN في ناتج التشغيل. تحذير Vite عن chunk رئيسي أكبر من 2MB ما زال قائمًا رغم اجتياز الميزانية؛ تقسيمه يحتاج قياس بدء تشغيل Quest.

## بروتوكول النظارة قبل الإغلاق

1. لكل Quest3/3S، ثم Quest2 عند الدعم: سجّل الطراز وHorizon OS وإصدار Browser وSHA ونسخة APK/الويب ونسبة البطارية وحرارة البداية.
2. ابدأ جلسة جديدة لكل نمط، واختبر VR ثم MR. افتح جميع الخامات، الرميات والطلقات؛ املأ التجمعات، اختبر Bricks/Fair/Rain والطقس الليلي والماء. صدّر JSON قبل الخروج من XR/تبديل السيناريو، أو بعد انتهاء الجلسة من صفحة الدخول.
3. اختبر طول المحتوى أو 45 دقيقة، الأقصر حسب VRC.Performance.1. يحتفظ عداد الإطارات بآخر 7200 عينة فقط؛ الأرقام المئوية نافذة متحركة والقمم منذ بداية العالم. صدّر مقاطع متتابعة؛ لا تصف نافذة 100 ثانية بأنها اختبار 45 دقيقة. أرفق قياس المنصة إن توفر على النظارة دون اشتراط أدوات حاسوب.
4. راقب فترات sustained أقل من60FPS والارتفاع الحراري وثبات72Hz المطلوبة. لا تفعّل90Hz كهدف حتى تثبت القياسات القدرة. اختبر فقدان التركيز وعودة التتبع بدون طلقة/رمية تلقائية.
5. افحص تصادم الغرفة الحقيقية، الطاولة والجدار والمراسي. راقب memory قبل وبعد20 تبديل نمط. ميّز JS heap عن ذاكرة GPU والعملية الكلية.
6. أرفق ملفات القياس الخام وفيديو المشكلات وسجل ظروف الاختبار؛ لا تعدل نتائج هذا التقرير إلى PASS اعتمادًا على لقطة شاشة.

لم يتم اختبار هذه النسخة على جهاز Meta Quest حقيقي، لذلك لا يمكن اعتبارها جاهزة نهائيًا للنشر في المتجر.

## نقل المرجع والفيزياء — 8 أكتوبر 2026، 20:12 UTC

هذه عينة جديدة من IWER/Chromium البرمجي في بيئة الاختبار، وليست جهاز Quest: 229 إطارًا خلال 24.18 ثانية، المتوسط 9.47 FPS؛ زمن الإطار المتوسط 105.59ms، وP95=208.80ms. الذاكرة المسجلة 91.7MB، والحد الأقصى 358 draw calls و262372 مثلثًا أثناء التنقل بين الأنماط والخامات. هذه الأرقام لا تحقق هدف النظارة ولا تصلح للتنبؤ بأدائها؛ يلزم قياس حقيقي قبل وصف النسخة بالسلسة. الحزمة الحالية نحو 11.76MB دون ضغط، والمحتوى المضغوط المفرد نحو 6.61MB؛ فحص حد الحجم ناجح.

`physicsHz=60` في مخطط التقرير القديم يصف Havok البيئي؛ دحروج وأنماط المرجع هنا تعمل بخطوة 120Hz. لا يوجد FPS مقاس على النظارة لهذا التعديل. المالك جرّب النسخة السابقة، وليس هذا دليلًا على اختبار التعديل الحالي.
